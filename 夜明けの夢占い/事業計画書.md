# 夜明けの夢占い 事業計画書

2026年10月17日 時点

「夜明けの夢占い」は、30〜40代女性向けのAI夢占いWebサービス。年間予算50万円未満で始め、公開から約1年で月売上約100万円・月利益約75万円（標準シナリオ）を目指す。課金を始める5か月目から黒字の計画。開発の詳細は「設計書.md」を参照。

## 1. 事業概要と利用者

| 項目 | 内容 |
| --- | --- |
| サービス名 | 夜明けの夢占い |
| 内容 | 見た夢を入力すると、AI夢占い師「朱音（あけね）さん」が、利用者の状況と悩みに合わせて読み解く |
| 主な利用者 | 30〜40代の女性。仕事・家庭・人間関係の悩みを抱え、朝の短い時間で心を整えたい人 |
| 提供の形 | まずWebサイト、次にスマホアプリ |
| 運営体制 | オーナー＋Claude（AI）で開発・運営 |
| 初年度の予算 | 50万円未満 |
| 1年後の目標 | 月売上100万円以上 |

## 2. 提供価値と強み

一般的な夢占いサイトは「辞書を引いて終わり」で、続けて使う理由が弱い。本サービスは次の3点で差をつける。

- **一人ひとりに合わせた結果**：決まった文章ではなく、夢の内容・夢の中の気持ち・年代や家族などの状況・今の悩みから、毎回AIが結果を作る
- **占い師のような対話**：朱音さんが結果の前に1問だけ問いかける。共感、対策つきの注意点、今日の小さな行動、希望の一言で結ぶ。売れている占い師の伝え方をAIに取り込んでいる
- **夢日記と心の変化の記録**：使うほど「よく見る夢」「最近の心の傾向」が分かり、月末に心のレポートが届く。自分だけの記録がたまるため、他のサービスに乗り換えにくい

こだわり：夢はすぐ忘れるため、開いてすぐ夢を入力でき、状況の質問はその後にする。不安をあおって課金させることはしない。

## 3. 収益モデルと料金

収益は3本立てで、柱は月額会員。

| 区分 | 料金 | 内容 | 使うAI |
| --- | --- | --- | --- |
| 無料 | 0円（広告あり） | AI夢占い1日1回、夢日記、夢辞典 | Claude Haiku 5.5 |
| 月額会員 | 月680円 | 1日3回まで、過去の夢を踏まえた深い読み解き、月末の心のレポート、LINEの朝の通知、広告なし | Claude Opus 5.5 |
| 都度課金 | 500〜1,500円 | 初夢の特別鑑定、半年分の夢の深層レポートなど | Claude Opus 5.5 |

- 決済はStripe（カード手数料3.6%、初期費用・月額費なし）
- 月額会員1人あたり、売上680円から決済手数料24円とAI利用料141円を引いて約515円（約76%）が残る

## 4. 集客と継続の施策

集客の主力は検索。「蛇の夢　意味」のように毎朝検索する人を、夢辞典ページからAI占いへ案内する。継続は「起きてすぐの30秒」を習慣にすることで生み出す。

### 集客

| 施策 | 内容 | 始める時期 |
| --- | --- | --- |
| 夢辞典（検索） | 夢のテーマ別の解説ページ。1年で300〜500ページ。最初の16テーマは決定済み | 公開前から |
| SNS | Instagramで「今日の夢の意味」を毎日投稿。Threads・Xも併用 | 公開時 |
| シェア機能 | 占い結果を画像でシェアし、利用者が広める | 公開時 |
| 広告 | Instagram広告・検索広告を月3万円から | 7か月目〜 |

### 継続

- 毎朝の通知（有料会員はLINE、無料利用者はメール）
- 一言・音声で入力できる手軽さ
- 連続記録日数、よく見る夢の分析
- 月末の心のレポート（月額会員）
- 初夢（1月）、新生活（4月）、誕生月などの季節企画
- 朱音さんが前回の夢に触れる（「先週の夢の続きのようですわね」）

## 5. 採算計画と損益分岐点

有料会員が約110人で毎月黒字になる。費用のほとんどが利用者数に応じて増えるため、大きな赤字にはなりにくい。

### 損益分岐点

- 毎月決まってかかる費用：約5.5万円（サーバー代約0.8万円＋LINE約1.7万円＋広告費3万円）
- 月額会員1人あたりの残り：約515円
- 5.5万円 ÷ 515円 ＝ 有料会員約110人
- 無料利用者は1人あたりAI費用約0.6円に対し広告収入約3円。増えても赤字にならない

### 3つのシナリオ

| シナリオ | 前提 | 12か月目の売上（円） | 12か月目の利益（円） | 1年間の累計利益（円） |
| --- | --- | --- | --- | --- |
| 慎重 | 利用者数が標準の半分、有料化率2% | 347,700 | 224,206 | 717,464 |
| 標準 | 12か月目に利用者3.3万人、有料化率3% | 997,200 | 746,388 | 2,586,492 |
| 強気 | 利用者数が標準の1.5倍、有料化率4% | 1,940,400 | 1,407,204 | 5,166,891 |

### 主な前提

- 月額680円、都度課金平均900円（利用者の約0.8%が毎月購入）、広告は1,000閲覧あたり200円（利用者1人月15閲覧）
- AI費用：Haiku 5.5 約0.16円／回（無料、月4回）、Opus 5.5 約6.3円／回（有料、月20回＋月末レポート約15円）
- LINEは有料会員のみ毎朝配信（ライトプラン5,000円・スタンダードプラン15,000円、税別）
- 1ドル＝150円。課金は5か月目から、広告費は7か月目から
- 含まないもの：オーナーの作業時間、税金（年間売上1,000万円超でその2年後から消費税）、アプリストアの手数料（15〜30%）
- 計算スクリプト：同じフォルダの「採算計算.py」（前提の数字を変えて計算し直せる）

## 6. 実行計画と目標数値

### 実行計画

1. **1か月目：準備**：AIの話し方（朱音さん）を作って試す、夢辞典を書き始める、開発開始
2. **2〜3か月目：Web版の公開**：無料のAI夢占い、夢日記、夢辞典、広告。SNS発信開始
3. **4〜6か月目：課金とLINE**：月額会員・都度課金（課金は5か月目から）、LINEの朝の通知
4. **7〜12か月目：拡大とアプリ化**：広告を開始、Webアプリ化、利用が定着したらストア版を検討

### 毎月見る数字

| 数字 | 意味 | 1年後の目標 |
| --- | --- | --- |
| 月の利用者数 | 1か月に1回以上使った人 | 約3.3万人 |
| 継続率 | 初回利用の1週間後も使っている割合 | 30%以上 |
| 有料化率 | 利用者のうち月額会員の割合 | 3% |
| 解約率 | 月額会員のうちその月にやめた割合 | 10%以下 |
| 月の売上 | 3つの収益の合計 | 100万円 |

公開後は実際の数字で毎月、採算を計算し直す。

## 7. リスクと対策

最大のリスクは費用ではなく、利用者を集められないこと。ただし利用者3,000人・有料会員60人で止まっても、月約1.4万円の黒字の計算。

| リスク | 対策 |
| --- | --- |
| 検索からの集客が伸びない | SNSとシェア機能を並行。夢辞典の品質を上げる |
| 使いすぎの会員でAI費用が膨らむ（月約100回以上で赤字） | 月額会員も「1日3回まで」の上限。毎月AI費用を確認 |
| LINEの配信料が増える（会員1,000人超） | 通知をメールやアプリ通知に切り替える。LINEは2026年10月の料金改定を確認 |
| AIが不適切な回答をする | 話し方のルールを決め、公開前にテスト用の夢100件で確認。危険な内容には相談窓口を案内 |
| 個人情報の漏えい | 集める情報を最小限にし、アクセス制御と削除機能を用意 |
| 霊感商法と見なされる | 不安をあおって課金させない。特商法表記と利用規約を整備 |
| スマホアプリ化で手数料が増える（15〜30%） | Webでの申し込みを主にし、アプリは継続利用のために使う |
