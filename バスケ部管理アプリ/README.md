# バスケ部ノート（バスケ部管理アプリ）

高校バスケットボール部向けの管理アプリ。4つの課題（チームビルディング・練習メニュー・戦術理解・個人の課題管理）と、スキル診断によるステップアップ練習を1つのアプリにまとめたもの。

- 形式：PWA（スマホのブラウザで開き「ホーム画面に追加」でアプリのように使える）
- サーバー：Python 標準ライブラリのみ（追加インストール不要）＋ SQLite
- 画面：日本語のみ・スマホ操作優先・ダークモード対応
- オフライン：一度開いた練習メニュー・作戦図などは電波がなくても閲覧可能

## いちばん簡単な起動方法（ダブルクリック）

1. https://github.com/35pa/ISDB/tree/claude/new-session-06hg01 を開き、緑の「Code」→「Download ZIP」でダウンロードして解凍（PR をマージした後は https://github.com/35pa/ISDB でも可）
2. `バスケ部管理アプリ` フォルダの中の起動ファイルをダブルクリック
   - Windows：`起動_Windows.bat`
     - 「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」
   - Mac：`起動_Mac.command`
     - 「開いていません」「開発元を確認できない」と出たら「完了」を押し、次のどちらかで起動
       - ターミナルに `bash `（後ろに半角スペース）と入力 → `起動_Mac.command` をターミナルにドラッグ → Enter
       - システム設定 →「プライバシーとセキュリティ」→「このまま開く」（1回許可すれば次からダブルクリックで起動）
3. 数秒でブラウザが自動で開く
   - ログイン：チームコード `DEMO22`／`coach`／パスワード `demo-pass1`
- Python が入っていない場合
  - Windows：自動でインストールするので、終わったらもう一度ダブルクリック
  - Mac：インストール画面が出るので「インストール」を押し、終わったらもう一度ダブルクリック
- 起動中に出る黒い画面（Mac は白い画面）は閉じないこと（閉じるとアプリが止まる）

## コマンドで起動する方法（デモデータ入り）

```bash
cd バスケ部管理アプリ
python サーバー.py --demo
```

- パソコンで http://localhost:8000 を開く
- 同じ Wi-Fi のスマホからは、起動時に表示される `http://192.168.x.x:8000` を開く
- デモのログイン情報
  - チームコード：`DEMO22`
  - コーチ：`coach`
  - 選手：`player1` 〜 `player8`
  - パスワード：全員 `demo-pass1`

## 本番の始め方

1. `python サーバー.py` で起動（データは `データ/バスケ部.sqlite3` に保存）
2. 顧問・コーチがログイン画面の「新しくチームを作る」からチームを作成
3. 表示された「チームコード」を控える
4. 「その他 → メンバー → ＋追加」で選手を登録し、表示されたログイン情報を選手に伝える
5. 選手は初回ログイン後「設定」からパスワードを変更

- 部外からアクセスさせる場合は、HTTPS 対応のサーバー（レンタルサーバー・クラウド等）に置くこと
  - サービスワーカー（オフライン機能）とスマホへのインストールは HTTPS か localhost でのみ動作
- バックアップは `データ/バスケ部.sqlite3` をコピーするだけ

## iPhone で試す（ウェブ版・お試し版）

- サーバーなしで、ブラウザだけで全機能が動く版
  - サーバーの Python（API_*.py など）を、ブラウザの中で動く Python（Pyodide）でそのまま実行
  - サンプルデータ入りのデモチームで開始。ログイン画面の「コーチとして試す」「選手として試す」ですぐ入れる
  - 入力したデータはその端末のブラウザの中だけに保存（ほかの人の端末とは共有しない）
  - 「その他 → 設定 → データを初期化する」で最初のサンプルデータに戻る
  - 初回は約16MBの読み込みあり（Wi-Fi 推奨）
  - 作戦図の画像保存・PDF 出力はお試し版では非表示
- iPhone での開き方
  - Safari で公開ページの URL を開く
  - 共有ボタン →「ホーム画面に追加」でアプリのように起動可能
- チーム全員でデータを共有して使う場合は、サーバー版（上の「本番の始め方」）が必要
- 作り直し方
  - `python ウェブ版/作成.py` → 「ウェブ版/出力/公開」に公開用のファイル一式ができる
  - 必要なもの：Node.js（esbuild でアプリの JavaScript を1つにまとめる）、初回のみインターネット接続（Pyodide を取得）
  - 手元での確認は「出力/公開/確認用.html」を簡易サーバー経由で開く

| セットプレー | ピック&ロール（トップ）、スペイン・ピック&ロール、UCLAカット、フレックス、ピンダウン（スタッガースクリーン）、ドリブル・ハンドオフ |
| リスタート | エンドラインから（ボックス）、サイドラインから（バックスクリーン） |
| 速攻 | 3レーン（3対2） |
| ゾーン攻略 | 1-3-1で2-3ゾーンを攻める |
| マンツー | マンツーマンの基本ポジション、ヘルプ&ローテーション、ピック&ロール守備（ショウ）、ピック&ロール守備（ドロップ） |
| ゾーン | 2-3ゾーン、3-2ゾーン、1-3-1ゾーン（トラップ） |
| 変則・プレス | ボックスワン、2-2-1フルコートプレス |

- 「作戦 → テンプレ」で分類ごとに絞り込み
- 「＋作成 → テンプレートから作る」でコピーして自分たちの形に編集可能
- 以前のバージョンで作ったチームには「その他 → 設定 → 標準のドリル・作戦テンプレートを追加」で、足りない分だけ追加（今あるデータは消えない）
  - 既にある標準テンプレートには、増えた理解度クイズだけを追加
  - 図を変更したテンプレートには、図の位置を使う問題（次の動き・タップ問題）は追加しない

## フォーメーションの理解度チェック

- 理解度クイズ（標準テンプレートに合計150問以上）
  - 基本：選択肢から選ぶ問題
  - 位置タップ：隠した選手の立ち位置を、図をタップして答える（例：5アウトで5番が立つ位置）
  - 次の動き：コマを途中で止め、黄色の輪の選手の「次の動き」を選ぶ（答えになる線は隠す）
  - 移動先タップ：黄色の輪の選手が次に動く先を、図をタップして答える。正解の範囲は緑の円
  - 選択肢の並びは問題ごとに混ぜて表示（いつも同じ番号が正解にならない）
- ポジション別の問題
  - 問題ごとに対象の選手（1番〜5番、ディフェンスは X1〜X5）を設定
  - 「自分のポジション」を選ぶと、そのポジション向けの問題だけ表示
  - フォーメーション・ゾーンのテンプレートは、5つのポジションすべてに専用の問題あり
- 実技チェック（コーチが記録）
  - コートで実際に動き、5人がそろって図のとおりに動けたかを記録
  - 記録内容：実施日、ポジションごとの選手とできたか、コマごとにできたか、全体のできばえ（できなかった／一部できた／5人でそろってできた）、メモ
  - 選手は自分が参加した記録の、自分の結果だけ見られる
- コーチ向け
  - クイズの追加・編集で種類・対象の選手・コマ・正解の位置（図をタップ）を設定
  - 「図から移動先タップ問題を自動作成」：コマの間で大きく動いた選手ごとに問題を自動作成
  - 選手の理解度表：理解度・クイズの正解数・最新の実技チェック。🏅＝習得（全問回答で8割以上正解＋実技で本人も全体もできた）

## スキル診断の仕組み

- 評価値：0〜100
- 総合値：入力された評価元だけで重み付き平均
  - コーチ評価 50%
  - スタッツ自動算出 30%
  - 自己評価 20%
- スキル項目（レーダーチャートの並び順）：ドリブル・パス・シュート・ディフェンス・基礎体力・リバウンド
- レベル（5段階）
  - 0〜19＝基礎（始めたばかり）
  - 20〜39＝初級
  - 40〜59＝中級
  - 60〜79＝上級
  - 80〜100＝プロ（全国・プロを目指すレベル）
- 基礎体力だけは体力測定の実測値で判定（記録があればコーチ評価・自己評価より優先）
  - 測定項目：身長・体重・指高・最高到達点・垂直跳び・立ち幅跳び・プロアジリティ・17往復シャトル
  - 垂直跳び＝同じ日に測った「最高到達点 − 指高」を自動計算
  - 各項目を「0点の値〜100点の値」で比例換算し、測った項目の平均が基礎体力スコア
    - 体重（体の強さ）40→100kg、最高到達点 230→340cm、垂直跳び 20→90cm、立ち幅跳び 150→300cm、プロアジリティ 6.2→4.2秒、17往復シャトル 80→50秒
    - 身長・指高は最高到達点に含まれるため記録のみ
  - コーチはチームの選手の、選手は自分の測定値を記録できる（スキル診断画面の「体力測定」）
  - 換算の基準は `体力測定.py` の先頭で変更可能
- 標準ドリル：基礎体力以外の5項目 × 5段階 × 各3〜4本（計76本）
  - すべて1人で実施・計測できる内容（準備する道具と距離、やり方、回数・秒数・成功数で決めたクリア条件）
  - 1対1やチームでの判断力はドリルではなく、コーチ評価で見る
- 優先項目：総合値の低い順に3つ
- スタッツ自動算出（直近10試合、2試合以上で算出）
  - シュート：実効FG%（＋FT%）
  - パス：アシスト数とアシスト／ターンオーバー比
  - リバウンド：1試合平均リバウンド
  - ディフェンス：1試合平均スティール＋ブロック
  - ドリブル：アシスト／（アシスト＋ターンオーバー）
- 自己評価とコーチ評価の差が20以上：注意表示
- 次の練習の決め方
  - スキルごとのドリルを基礎→初級→中級→上級→プロの段階順に並べる（「次のステップ」でつなぐ）
  - 診断レベルより下のドリルは飛ばす
  - 完了していない最初のドリルを提示
  - 選手が「クリア条件を満たした」と報告すると完了になり、次のドリルが自動で「実施中」に
  - コーチの上書き指定があればそちらを優先（クリアすると指定は自動解除）
- 閾値・重みは `スキル診断.py` の先頭で変更可能

## セキュリティ・データ分離

- 全データにチームIDを付け、API は必ずログイン中のチームのデータだけを返す
  - 他チームの ID を指定しても「見つかりません」
- 権限
  - 選手が見られるのは自分のカルテ・スキル診断のみ
  - 顔写真・学年・背番号などの個人情報の編集はコーチのみ
- パスワード：PBKDF2（20万回）でハッシュ化、ログイン失敗5回で5分停止
- 画面：HTML を文字列で組み立てない（XSS 対策）、CSP ヘッダー付き
- ログアウト時：オフライン用に保存した API 結果を消去（共有端末対策）

## 今後の拡張の余地

- 保護者閲覧：`users.role` に `guardian` を追加し、ルーティングの権限（`公開` / `ログイン` / `コーチ`）に閲覧専用の区分を足す
- 対戦相手データ：`opponents` テーブルを追加し、`events`（試合）と `stats` に相手IDを持たせる
- 1ユーザー複数チーム：`users` をアカウントとチーム所属に分ければ対応可能
