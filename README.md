# Amazonアフィリエイト × Claude × X 自動投稿

Amazonアソシエイトの商品を Claude（Anthropic API）で「売れる投稿文」にし、X（旧Twitter）へ自動投稿する仕組み。
GitHub Actions のスケジュール実行で完全放置運用が可能。

## 仕組み

```mermaid
flowchart LR
    A[商品リスト.csv<br/>ジャンル・ターゲット・商品・口調] --> B[自動投稿.py]
    P[プロンプト.md] --> C
    B --> C[Claude API<br/>候補を3件生成＋伸びる確率で採点]
    C --> D[最高得点の候補を採用]
    D --> E[X API v2<br/>1本目: 本文＋#PR<br/>2本目(リプライ): 誘導文＋【PR】＋リンク]
    E --> F[投稿履歴.json<br/>自動コミット]
    G[GitHub Actions<br/>毎日 12:00 / 20:00 JST] --> B
```

- 4つの変数: `商品リスト.csv` の「ジャンル・ターゲット・商品名・口調」を `プロンプト.md` に差し込んで Claude に指示
- 複数候補と採点: 切り口の違う候補を3件作らせ、共感度・具体性・クリック誘導・拡散性の内訳付きで「伸びる確率」を採点。最高点を自動採用
- 投稿構成: 1本目に本文（＋ハッシュタグ・#PR）、そのリプライに「ここからチェックできるよ👇」＋【PR】＋アフィリエイトリンク
- 法令対応: 本文に #PR、リンク直上に【PR】を自動付与（ステマ規制対応）
- 文字数: X の重み付き文字数（全角2・URL23）を計算し、上限 280 に自動調整
- 商品の選び方: 一番長く投稿していない商品を自動選択（未投稿を最優先）
- 履歴: 採用文・不採用候補・採点を `投稿履歴.json` へ追記し、Actions が自動コミット

## ファイル構成

| ファイル | 役割 |
|---|---|
| `自動投稿.py` | メイン。商品選択 → 生成 → 採用 → スレッド投稿 → 履歴保存 |
| `プロンプト.md` | Claude への指示文の雛形。`{ジャンル}` `{ターゲット}` `{商品名}` `{口調}` を差し込み。手動で Claude に貼って使うことも可 |
| `投稿文生成.py` | Claude API 呼び出し（構造化出力・複数候補・採点・拒否時フォールバック） |
| `X投稿.py` | X API 投稿（本文＋リプライ）、文字数計算、PR 表記の付与 |
| `アフィリエイトリンク.py` | ASIN + トラッキングID からリンク生成 |
| `商品リスト.csv` | 投稿する商品と変数の一覧（ここを編集して商品を追加） |
| `投稿履歴.json` | 投稿済み記録（自動更新） |
| `テスト_自動投稿.py` | ユニットテスト |
| `環境変数の設定例.txt` | `.env` の雛形 |
| `.github/workflows/自動投稿.yml` | 定期実行ワークフロー |
| `導入手順.md` | セットアップ手順（API取得〜運用開始） |

## クイックスタート

```bash
pip install -r requirements.txt
cp 環境変数の設定例.txt .env   # 値を書き換える
python 自動投稿.py --dry-run     # 候補・採点・投稿文を表示（投稿しない）
python 自動投稿.py               # 実際に投稿
python 自動投稿.py --asin B0XXXXXXX1   # 商品を指定して投稿
python -m unittest テスト_自動投稿 -v   # テスト
```

`商品リスト.csv` のサンプル行（子供の教育・知育ジャンル4商品）の ASIN はダミー。実際の Amazon 商品ページ URL の `/dp/` 直後の英数字10桁に置き換えてから使うこと。

詳細は `導入手順.md` を参照。
